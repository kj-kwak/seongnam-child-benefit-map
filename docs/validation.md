# 구현 검증 기록

2026-09-28 기준.

## 완료

- 타입 검사, ESLint, Next.js 15.5.26 프로덕션 빌드 통과.
- 단위/통합 테스트 14개: 499건 이후 업종 검색, 주소/지역/즐겨찾기 조건, 데이터 무결성, 20% 감소 차단, 세션 만료/변조/교체, Origin 검사, Preview 변경 차단, 후보 SHA 확인, 데이터 파일 허용 목록, 승인/복구 동작. GitHub 변경 API는 모의 응답으로 검증.
- Playwright 12개: 데스크톱 및 iPhone 크기 Chromium에서 검색, 숫자 이름 선택, 공유 주소 복원, 즐겨찾기 영속성, 없어진 가맹점, 빈 검색, 지도 실패 대응, 비밀 링크 세션, 무권한/다른 출처 요청 차단, 실제 포인터 드래그·모바일 스크롤·가로 넘침, 데이터 재시도·위치 거부 검증.
- Agent Browser로 데스크톱/모바일 화면을 직접 확인. 브라우저 page error 없음.
- 실제 10,398건 데이터 검색 계산 평균 약 3ms (로컬 환경). React 화면 갱신과 카카오 SDK 렌더링까지 포함한 성능 수치는 아님.
- 신한카드 실제 조회 API 한 구간(분당구 가구) 전체 페이지 138건 수집 확인. 기존 좌표 재사용 94건, 본인 REST 키 미설정으로 좌표 미확인 44건. 1/93 구간 smoke 수집은 불완전한 결과로 실패 처리되고 승인 후보를 만들지 않음.
- Vercel 원격 빌드 및 기본 주소의 공개 페이지·버전 API 응답 확인. 관리자 API는 무권한 요청에 401.

## 외부 설정 후 남은 검증

- 본인 카카오 JavaScript 키와 허용 도메인을 등록한 실제 지도 표시, 지도 이동/확대/군집/동일 좌표 가맹점 선택.
- 전체 지역·업종 수집 및 본인 REST 키를 이용한 신규 주소 좌표 변환.
- 해당 저장소로 제한한 관리자 GitHub 토큰 설정 후 실제 후보 승인 → GitHub 병합 → Vercel 자동 배포 → 반영 완료, 실제 이전 데이터 복구.
- Vercel GitHub App의 저장소 접근 권한을 추가하고 Git 자동 배포 연결.

현재는 기존 공개 자료를 이용한 확인용 배포이며, 위 설정이 끝나기 전에는 최신 가맹점 정보의 운영 완료로 표시하지 않습니다. 일일 수집 workflow는 `COLLECTION_ENABLED=true`로 활성화하기 전까지 예약 실행을 건너뜁니다.
